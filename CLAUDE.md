# MBTI Personality Predictor

A project to predict personality types using various metrics and visualizations.

## Tech Stack
- **Frontend**: React 18.3.1
- **Build Tool**: Vite 5.4.21
- **Styling**: Tailwind CSS 3.4.19
- **Charts**: Recharts 2.15.4
- **Animations**: Framer Motion 13.4.0
- **Testing**: Vitest, JSDOM, React Testing Library

## Commands
- `npm run dev`: Start development server
- `npm run build`: Build for production
- `npm run lint`: Run ESLint
- `npm run test`: Run tests
- `npm run preview`: Preview production build

## Guidelines
- Follow React 18 functional component patterns.
- Use Tailwind CSS for all styling.
- Use Recharts for data visualizations.
- Use Framer Motion for UI animations.
- Ensure components are tested with Vitest and React Testing Library.
